# Blue Lotus Kitchen Website

A single-page restaurant website for **Blue Lotus Kitchen**, a Chinese & South Indian restaurant in Ramesh Nagar, New Delhi. Visitors can browse the menu, build an order list and send a table booking request on WhatsApp.

**Live Site:** [blue-lotuswebsite.netlify.app](https://blue-lotuswebsite.netlify.app/)

> This is a demo project built for learning and portfolio purposes. Food photos are from Unsplash.

## Features

- Hero section with restaurant introduction and quick actions (view menu, book a table)
- "Two Kitchens" section for South Indian and Chinese cuisine
- Signature dishes section filled in dynamically with JavaScript
- Menu with category tabs, a veg-only toggle and a search box
- Order bar with a "plate" view that shows the item count and estimated total
- Send the order on WhatsApp or copy the order list
- Table booking form (name, guests, date, time) that opens a ready-made WhatsApp message
- Photo gallery, address, timings, Google Maps and call links

## Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts (Playfair Display, Manrope)
- Inline SVG icons

1. Download or clone this repository.
